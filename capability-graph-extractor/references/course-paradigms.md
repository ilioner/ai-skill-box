# 课程范式选择

## 不先入为主

宿主模型根据课程性质、培养对象和材料内容判断范式。课程名称关键词只能提供线索，不能替代判断。混合课程可同时使用多条来源链。

## 职业教育专业课

核心问题是“学生面向哪些岗位和典型工作任务，需要完成什么”。优先依据企业调研、职业标准、岗位规范、典型工作过程和专业教学标准。

常用链路：岗位 → 典型工作任务 → 工作步骤/情境 → 综合职业能力 → 子能力 → 项目任务 → 资源 → 评价。

能力可考虑专业能力、方法能力、社会能力；关系可考虑平行、递进、包容。工作过程可参考资讯、决策、计划、实施、检查、评价，但仅在课程材料或专业实践适用时使用。

## 公共基础课

不虚构职业岗位。核心问题是“学生面对哪些发展任务和典型学习、生活、社会情境，需要形成什么可迁移能力”。

常用链路：上位教育要求 → 课程目标 → 学生发展任务 → 典型情境 → 可迁移能力 → 活动/任务 → 资源 → 评价。

## 理论基础课

可从学科实践、问题解决和后续课程需求出发，避免把知识目录直接改名为能力。能力可以表现为解释、建模、论证、实验、分析、设计或迁移应用。

## 实践/项目课程

优先从最终作品、操作任务、项目流程、质量规范和评价量规反推能力，同时校验是否有上位课程目标和专业标准依据。

## 混合范式

例如公共课含职业情境时，职业情境可作为应用场景，但不应把课程整体伪装成岗位课程。记录每个能力采用的来源链与适用范围。
