# 四图谱节点与关系

## 节点类型

- `capability`：学生最终能够完成的行动或复杂任务
- `knowledge`：完成行动所需的概念、原理、规则、程序知识
- `quality`：价值观、职业规范、责任意识、社会/思政素养
- `question`：用于激活、诊断、探究或迁移学习的问题

可按需要增加 `course`、`module`、`task`、`activity`、`resource`、`assessment`、`position`、`work_task`、`scenario`、`standard`，但不要把所有文本都强行塞入四类核心节点。

## 常用关系

- `requires_knowledge`：能力需要知识支撑
- `develops_quality`：能力实践促进素养形成
- `driven_by_question`：问题驱动能力学习或应用
- `depends_on`：前置能力依赖
- `progresses_to`：由低复杂度向高复杂度递进
- `contains`：综合能力包含子能力
- `parallel_with`：同层并列，仅在确有表达价值时使用
- `implemented_by`：能力通过任务/活动实施
- `supported_by_resource`：资源支撑节点学习
- `assessed_by`：评价任务提供能力证据
- `derived_from`：节点来源于标准、岗位任务或发展情境
- `part_of`：节点属于课程、模块或任务

## 关系证据

每条关系必须至少具备：起点、终点、关系类型、来源或推断理由、证据状态、审核状态。不要仅因两个节点出现在同一章节就认定存在依赖关系。

## 职业课程主链

岗位/职业标准 → 典型工作任务 → 综合职业能力 → 子能力 → 课程项目/学习任务 → 知识与素养 → 资源与评价。

## 公共基础课程主链

上位教育要求/课程目标 → 学生发展任务 → 典型学习生活情境 → 可迁移能力 → 教学任务/活动 → 知识与素养 → 评价证据。

## 闭环检查

核心能力应尽量同时回答：来源是什么、由什么知识支撑、在哪个任务中培养、使用什么资源、通过什么表现评价。缺少任何一环时标记缺口，不自动补造。
